01 / 默认省预算

烟台老城 ⇄ 威海 · 客运班车

酒店→客运上车站→威海落客站→酒店

烟台查“烟台汽车总站”或“烟台旅游汽车站（火车站北广场）”；威海查“威海汽车站”，部分班次另停威海北站等，必须按订单确认。汽车站与火车站不要混叫。

门到门留3-4小时，含接车、候车和落客后再接驳。票价暂留30-50元/人，平台当前有约30元参考票；市内接驳另计。

查看班车线索 ↗出行日可售班次以运营方为准。烟台交运咨询：400-636-9369；可在“威海交运”查询反向车票。别照抄旧末班时间。
02 / 两三人可比较

正规网约车 · 酒店到酒店

烟台老城酒店→威海酒店

少搬一次行李，适合带长辈或多人合乘。按约1.5-2.5小时行车估算，取行李、等车一起留2-3小时；节假日、雪天再加余量。

暂留180-320元/车作规划，两人均摊约90-160元/人。以出发时平台报价、车型及高速费规则为准。

这是估算，不是已询定的包车价。走正规平台并核对司机车辆；接紧迫航班不依赖可能取消的顺风车。
03 / 从牟平出发更合适

牟平站 ⇄ 威海 / 威海北 · 动车

老城 / 养马岛→牟平站→威海车站→酒店

官方今年7月所说“最快13分钟到烟台”，指威海（北）站到牟平站。牟平属于烟台，但离烟台山、朝阳街还有一段陆路。

从老城出发，可按60-90分钟到牟平站＋提前30-45分钟到站＋实际列车时长＋威海接车估算，总体约2.5-4小时，再按真实车次重算。

核对“13分钟”的范围 ↗已在养马岛/牟平更值得比较；牟平站到养马岛入口官方参考约15分钟打车，本版留20-35分钟，岛内另算。铁路票价按12306，不默认烟台站有短时直达。
到站后住哪里、再走多久？＋

烟台站 → 老城

烟台山、朝阳街酒店：出租/网约车约10-20分钟。按站内指引到指定上车区；向司机发完整酒店名称。

芝罘站 / 牟平站 → 老城

芝罘站至老城约30-50分钟；牟平站约60-90分钟。车票写哪个站就去哪个站，不把它们当烟台站。

威海北站 → 浴场 / 市中心

国际海水浴场约10-20分钟；威高广场约25-40分钟。西侧海边住宿先比较这个站的真实车次。

威海站 → 韩乐坊 / 市中心

韩乐坊约5-15分钟接车或按入口步行；威高广场约25-40分钟；浴场约40-60分钟。威海汽车站在这一片，但不是同一候车厅。

以上为出租/网约车规划时间，不含站内步行、排队与堵车；公交需按“烟台公交时刻”或“威海公交”查询当天路线，不能套用这些时长。

机场、蓬莱和上岛码头怎么接？＋

烟台蓬莱国际机场 YNT

老城打车约60-90分钟；蓬莱城区约40-60分钟。机场巴士还需候车、经停，按实际线路另算，不能套用专车时长。

机场官方巴士入口 ↗

抵达T2到达厅6号门可问机场巴士；公众号“烟台交运机场巴士”核对出行日班次、票价与上车点。

威海大水泊机场 WEH

到威海站/韩乐坊约40-60分钟，到威高广场约50-80分钟，到西侧浴场可留70-100分钟。机场远在文登方向，不能按市内短途安排。

到达后按机场标识选择正规机场巴士、出租或网约车；巴士问清是否到酒店片区及末班，晚到提前落实接车。

去长岛：蓬长客港

烟台老城到港约1.5-2小时行车，接驳候船再加余量。蓬莱站到客港另留约30-45分钟出租接车；蓬莱站、机场与客港是三处地方。

导航搜“蓬长客港”。从港口到长岛需坐船，航程约45分钟；查“长岛船票”当天停复航和可售航班。

去刘公岛：刘公岛客运中心

威高广场酒店接车约10-25分钟，另外提前30-45分钟安检候船。不要把海上的“刘公岛”设为打车下车点。

乘机一般按起飞前约2小时到机场倒推；列车按至少提前30-45分钟到站倒推，航司/铁路具体规则优先。冬季结冰或大风雪增加余量。

四套行程已统一按上述接驳重排；班车需先订妥，晚到自动删下午海岸。预算按班车30-50元/人计算，改网约车只替换这一项，不重复相加。

烟台南站停办客运：不要作为本版到发站，详见交通指南。跨烟威默认客运班车或正规网约车；经牟平动车另计两端接驳。

船：刘公岛约20分钟航程，长岛约45分钟；安检、候船、上下船另算。不要用最后一班船接不可错过的航班。

查交通：铁路用12306，班车查运营方当日可售班次。天气、道路和季节线路会变，导航时间只是参考。

⌂住宿选哪个片区位置实用，安静与可退优先＋

烟台：朝阳街南段、大马路、烟台山附近；避开酒吧和主干道临街房。

威海：威高广场、幸福公园一带适合本版路线。纯海边度假可住西侧浴场，但去刘公岛和韩乐坊要另坐车。

长岛：南长山岛港口、明珠广场/文化街片区。接站是否含送站、停航能否退房，保留书面规则。

蓬莱：蓬长客港或蓬莱阁周边；返程机场和车站分清。平日常规房可先按200-350元/间/晚筛，暑期和假期看实际报价。

所有住宿建议均为片区参考，没有声称亲自住过某家酒店。

♧吃什么，怎么点胶东海鲜，也留一点家常味＋

烟台：焖子作小吃，鲅鱼水饺、海肠捞饭、清蒸鱼或家常鲁菜作正餐。

威海：胶东鱼菜、饺子、贝类；想吃韩餐可选一顿韩乐坊，不为几个网红店频繁跨片区。

蓬莱：小面适合早餐，份量先问。长岛渔家包餐先问几餐、几人、菜品与加工费。

两人一餐先点一个主食、一份海鲜、一份蔬菜。海鲜问清每斤/每份/每只、重量、活鲜或冰鲜与加工费，确认总价后再做。早餐15-30元、普通正餐40-80元/人为规划额度。
